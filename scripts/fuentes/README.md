# Fuentes de los reportes

Los reportes HTML de k0lmenIA incrustan estas fuentes (en base64) para verse igual en cualquier
máquina y sin internet. Son las mismas que usa https://k0lmena.com:

- `saira.woff2` — Saira (variable, pesos 500–700), para títulos.
- `inter.woff2` — Inter (variable, pesos 400–600), para el texto.
- `jetbrains-mono.woff2` — JetBrains Mono (variable, pesos 400–700), para código, IDs, etiquetas y números alineados.

Licencia: SIL Open Font License 1.1 (`OFL-Saira.txt`, `OFL-Inter.txt`, `OFL-JetBrainsMono.txt`).
Las mismas fuentes están en `docs/assets/fuentes/` para la web y los diagramas.
