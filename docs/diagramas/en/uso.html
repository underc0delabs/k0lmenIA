A single configuration

The root .env: URLs, credentials, k0lmena and test management. Never committed.

Doesn't make things up

Searches Jira, Confluence and Figma; what it can't find is recorded as Missing information (FI-01) in every report.

Saves tokens

What repeats is automated once and runs with npm, with no agents.

Traceability

HU-001 → CP-001 → @CP-001 → key in Xray/QMetry/AIO/Zephyr → result.
