One configuration

The root .env: URLs, credentials, k0lmena and test management. Never committed.

No invention

It searches Jira and the project documentation; what it doesn't find becomes Missing information (FI-01) in every report.

Saves tokens

What repeats is automated once and runs with npm, without agents.

Traceability

HU-001 → CP-001 → @CP-001 → key in Xray or k0lmenaTMT → result.

Task list

Write one task per line in TAREAS.md and ask "Hacé las tareas de TAREAS.md": it does them in order and marks each one.
