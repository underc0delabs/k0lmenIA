k0lmenIA · Getting started

Install, set your tokens in the .env and start asking the agents for things

QARMY · Underc0de

1Get it running

A few minutes, only once

1
RequirementsPython 3.10+ · Node.js 20+ (22 LTS recommended) · VS Code + Claude Code (Claude account or Anthropic API). Optional: Java 8+ (JMeter), Docker (security), JDK + Android SDK or Xcode (mobile).
2
Clone the repository
git clone https://github.com/underc0delabs/k0lmenIA.git
cd k0lmenIA
3
Install the dependencies
pip install -r requirements.txt # Mac/Linux: pip3
npm install # installs k0lmena
4
Create your .env
cp .env.example .env # PowerShell: copy
Fill in only what you'll use (column 2).
5
Check that everything is ready
npm run doctor # says what's missing and how
6
Open Claude Code
code .
claude # asks you to sign in the 1st time
For extra browsers: cd herramientas/k0lmena · npx playwright install chromium firefox webkit

2Set tokens in the .env

A single file, at the root · never versioned · the agents never ask for tokens in the chat

APP_USER=… · APP_PASSWORD=…
BASEURL=(if empty, uses APP_URL)

Jira and Confluence atlassian connector (active)
OAuth from /mcp, or with a token:

JIRA_BASE_URL · JIRA_EMAIL · JIRA_API_TOKEN

Optional: ESTIMACION_FACTOR=1.3 (estimated time × 1.3)

If a fact is missing

The agent doesn't make it up: it returns "Necesito que confirmes" (I need you to confirm) and Claude asks you.

Actions with side effects

Writing to a database, creating data in Jira/Xray or running load: always with your ok.
