K0lmenIA Light · Getting started

Install, set your tokens in the .env and start asking the agents for things

QARMY · Underc0de

1Get it running

A few minutes, only once

1
RequirementsPython 3.10+ · Node.js 20+ (22 LTS recommended) · VS Code + Claude Code (Claude account or Anthropic API).
2
Clone the repository
git clone https://github.com/underc0delabs/k0lmenIA.git
cd k0lmenIA
3
Install the dependencies
pip install -r requirements.txt # Mac/Linux: pip3
npm install # installs k0lmena
4
Create your .env
cp .env.example .env # PowerShell: copy
Fill in only what you'll use (column 2).
5
Check that everything is ready
npm run doctor # says what's missing and how
6
Open Claude Code
code .
claude # asks you to sign in the 1st time
For extra browsers: cd herramientas/k0lmena · npx playwright install chromium firefox webkit
Or without cloning: as a Claude Code plugin. /plugin marketplace add underc0delabs/k0lmenIA · /plugin install k0lmenia@k0lmenia · in your project, k0lmenia init and k0lmenia doctor. Commands are k0lmenia <x>, and it updates with /plugin marketplace update k0lmenia without touching your work.

2Set tokens in the .env

A single file, at the root · never versioned · the agents never ask for tokens in the chat

App under test E2E, mappers
APP_URL=https://staging.tu-app.com
APP_USER=… · APP_PASSWORD=…
BASEURL=(if empty, uses APP_URL)
API Newman, API suite
API_BASEURL=https://api.tu-app.com · API_TOKEN=<your-token>
Jira atlassian connector (active)
OAuth from /mcp, or with a token:
ATLASSIAN_MCP_AUTENTICACION=token
JIRA_BASE_URL · JIRA_EMAIL · JIRA_API_TOKEN
Test management scripts/gestion
GESTION_HERRAMIENTA=xray-cloud | xray-dc | k0lmena-tmt
GESTION_PROYECTO=PROJ
Xray Cloud: XRAY_CLOUD_CLIENT_ID · XRAY_CLOUD_CLIENT_SECRET
Xray DC: XRAY_DC_URL · XRAY_DC_TOKEN
k0lmenaTMT: K0LMENA_TMT_TOKEN
Optional: ESTIMACION_FACTOR=1.3 (estimated time × 1.3)
App repository documentador-proyecto
REPO_RUTA_LOCAL=C:/repos/mi-app
Databases
DB_CONEXIONES=principal + DB_PRINCIPAL_MOTOR · _HOST · _BASE · _USUARIO · _CLAVE
Notifications Slack/Teams
SLACK_WEBHOOK_URL · TEAMS_WEBHOOK_URL
Browser, bot protection and language npm test, tools, agents
NAVEGADOR_CANAL=chrome · RITMO_HUMANO=si
QA_BYPASS_HEADER=X-QA-Bypass · QA_BYPASS_TOKEN=…
DOCUMENTACION_EN=(empty: Claude asks) | si | no
Optional connector k0lmenaTMT: npm run conector -- activar k0lmena-tmt, restart Claude Code and check with /mcp. Use test credentials, never production ones.

In natural language: Claude Code picks the agent (or you name it)

If a fact is missing

The agent doesn't make it up: it returns "Necesito que confirmes" (I need you to confirm) and Claude asks you.

Actions with side effects

Writing to a database, creating data in Jira/Xray or running load: always with your ok.

Saves tokens

What's automated runs with npm test, with no agents.

Everything ends up in

output/ (HTML reports in Spanish and English, with the last 5 runs in historial/ and the index.html portal) and herramientas/k0lmena/ (automation).
