Agente vs. skill

El agente es quién hace la tarea entera; el skill es cómo se hace una parte, y lo comparten varios agentes.

Script vs. herramienta

Un script es código propio del repo para formato y cálculo; una herramienta es software de testing externo (k0lmena, Newman, ZAP).

MCP vs. herramienta

MCP conecta a Claude Code con un sistema externo para leerlo o escribirle; una herramienta se ejecuta por terminal.

Para crecer

Sumar una capacidad es sumar una pieza: un agente, un skill, un conector, una herramienta o un script (ver ARQUITECTURA.md). El plugin k0lmenia se arma solo desde este repo.
