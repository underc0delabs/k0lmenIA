k0lmenIA · Puesta en marcha

Instalá, configurá tus tokens en el .env y empezá a pedirle cosas a los agentes en español

QARMY · Underc0de

1Poner en marcha

Unos minutos, una sola vez

1
RequisitosPython 3.10+ · Node.js 20+ (22 LTS recomendado) · VS Code + Claude Code (cuenta de Claude o API de Anthropic). Opcionales: Java 8+ (JMeter), Docker (seguridad), JDK + Android SDK o Xcode (mobile).
2
Cloná el repositorio
git clone https://github.com/underc0delabs/k0lmenIA.git
cd k0lmenIA
3
Instalá las dependencias
pip install -r requirements.txt # Mac/Linux: pip3
npm install # instala k0lmena
4
Creá tu .env
cp .env.example .env # PowerShell: copy
Completá solo lo que vayas a usar (columna 2).
5
Revisá que esté todo listo
npm run doctor # dice qué falta y cómo
6
Abrí Claude Code
code .
claude # la 1ª vez pide autenticarte
Para navegadores extra: cd herramientas/k0lmena · npx playwright install chromium firefox webkit

2Configurar tokens en el .env

Un solo archivo, en la raíz · nunca se versiona · los agentes nunca piden tokens por el chat

App bajo prueba E2E, mappers, exploratorias, visual
APP_URL=https://staging.tu-app.com
APP_USER=… · APP_PASSWORD=…
BASEURL=(si queda vacío, usa APP_URL)
API Newman, suite de API, k6
API_BASEURL=https://api.tu-app.com · API_TOKEN=<tu-token>
Jira y Confluence conector atlassian (activo)
OAuth desde /mcp, o con token:
ATLASSIAN_MCP_AUTENTICACION=token
JIRA_BASE_URL · JIRA_EMAIL · JIRA_API_TOKEN
Gestión de pruebas scripts/gestion
GESTION_HERRAMIENTA=xray-cloud | xray-dc | qtm4j | aio | zephyr-scale
GESTION_PROYECTO=PROJ
Xray Cloud: XRAY_CLOUD_CLIENT_ID · XRAY_CLOUD_CLIENT_SECRET
Xray DC: XRAY_DC_URL · XRAY_DC_TOKEN
QMetry: QTM4J_API_KEY · AIO: AIO_API_TOKEN
Opcional: ESTIMACION_FACTOR=1.3 (tiempo estimado × 1,3)
Repositorio de la app documentador-proyecto
REPO_PROVEEDOR=github | gitlab | azure-repos | bitbucket
REPO_NOMBRE=mi-empresa/mi-app · GITHUB_TOKEN · GITLAB_TOKEN
Azure DevOps conector azure-devops
ADO_ORGANIZACION · ADO_PAT · ADO_PROYECTO
Bases de datos y seguridad
DB_CONEXIONES=principal + DB_PRINCIPAL_MOTOR · _HOST · _BASE · _USUARIO · _CLAVE
SEGURIDAD_URLS_AUTORIZADAS=https://staging.tu-app.com
Correos, idiomas, roles y avisos correos, traductor, permisos, Slack/Teams
MAILPIT_URL=http://localhost:8025
TRADUCTOR_IDIOMAS=es-AR,en-US,pt-BR
PERMISOS_ROLES=admin,operador + PERMISOS_<ROL>_USUARIO · _CLAVE
SLACK_WEBHOOK_URL · TEAMS_WEBHOOK_URL · MONITOREO_URLS
Mailpit: docker compose -f herramientas/mailpit/docker-compose.yml up -d
Conectores opcionales (Azure DevOps, Figma, GitHub, GitLab, Linear, ClickUp, monday, Asana, Trello, Notion, YouTrack, Shortcut, QMetry, AIO Tests, k0lmenaTMT, Appium): npm run conector -- activar <nombre>, reiniciá Claude Code y verificá con /mcp. Usá credenciales de prueba, nunca de producción.
