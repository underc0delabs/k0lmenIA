K0lmenIA Light · Puesta en marcha

Instalá, configurá tus tokens en el .env y empezá a pedirle cosas a los agentes en español

QARMY · Underc0de

1Poner en marcha

Unos minutos, una sola vez

1
RequisitosPython 3.10+ · Node.js 20+ (22 LTS recomendado) · VS Code + Claude Code (cuenta de Claude o API de Anthropic).
2
Cloná el repositorio
git clone https://github.com/underc0delabs/k0lmenIA.git
cd k0lmenIA
3
Instalá las dependencias
pip install -r requirements.txt # Mac/Linux: pip3
npm install # instala k0lmena
4
Creá tu .env
cp .env.example .env # PowerShell: copy
Completá solo lo que vayas a usar (columna 2).
5
Revisá que esté todo listo
npm run doctor # dice qué falta y cómo
6
Abrí Claude Code
code .
claude # la 1ª vez pide autenticarte
Para navegadores extra: cd herramientas/k0lmena · npx playwright install chromium firefox webkit
O sin clonar: como plugin de Claude Code. /plugin marketplace add underc0delabs/k0lmenIA · /plugin install k0lmenia@k0lmenia · en tu proyecto, k0lmenia init y k0lmenia doctor. Los comandos son k0lmenia <x> y se actualiza con /plugin marketplace update k0lmenia sin tocar tu trabajo.

2Configurar tokens en el .env

Un solo archivo, en la raíz · nunca se versiona · los agentes nunca piden tokens por el chat

App bajo prueba E2E, mappers
APP_URL=https://staging.tu-app.com
APP_USER=… · APP_PASSWORD=…
BASEURL=(si queda vacío, usa APP_URL)
API Newman, suite de API
API_BASEURL=https://api.tu-app.com · API_TOKEN=<tu-token>
Jira conector atlassian (activo)
OAuth desde /mcp, o con token:
ATLASSIAN_MCP_AUTENTICACION=token
JIRA_BASE_URL · JIRA_EMAIL · JIRA_API_TOKEN
Gestión de pruebas scripts/gestion
GESTION_HERRAMIENTA=xray-cloud | xray-dc | k0lmena-tmt
GESTION_PROYECTO=PROJ
Xray Cloud: XRAY_CLOUD_CLIENT_ID · XRAY_CLOUD_CLIENT_SECRET
Xray DC: XRAY_DC_URL · XRAY_DC_TOKEN
k0lmenaTMT: K0LMENA_TMT_TOKEN
Opcional: ESTIMACION_FACTOR=1.3 (tiempo estimado × 1,3)
Repositorio de la app documentador-proyecto
REPO_RUTA_LOCAL=C:/repos/mi-app
Bases de datos
DB_CONEXIONES=principal + DB_PRINCIPAL_MOTOR · _HOST · _BASE · _USUARIO · _CLAVE
Avisos Slack/Teams
SLACK_WEBHOOK_URL · TEAMS_WEBHOOK_URL
Navegador, anti-bots e idioma npm test, herramientas, agentes
NAVEGADOR_CANAL=chrome · RITMO_HUMANO=si
QA_BYPASS_HEADER=X-QA-Bypass · QA_BYPASS_TOKEN=…
DOCUMENTACION_EN=(vacío: Claude pregunta) | si | no
Conector opcional k0lmenaTMT: npm run conector -- activar k0lmena-tmt, reiniciá Claude Code y verificá con /mcp. Usá credenciales de prueba, nunca de producción.

3Pedírselo a los agentes

En lenguaje natural: Claude Code elige el agente (o nombralo vos)

Análisis y diseño
"Documentá el proyecto"
documentador-proyectonuevo repositorio, historias, links y web
"Analizá la historia HU-001 y decime qué falta definir"
analista-historias
"Generá los casos de prueba de PROJ-12"
generador-casos-manuales Excel con tiempo estimado + cobertura
"Revisá los casos de HU-001 y decime cuánto lleva ejecutarlos"
revisor-casos puntaje, duplicados y minutos
"¿Este bug ya está cargado en Jira?"
triador-bugsnuevo duplicados y regresiones
Ejecución en vivo
"Ejecutá CP-001 de HU-001 contra https://tu-app.com en headless"
ejecutor-e2e reporte con capturas
"Acompañame a ejecutar los casos de HU-012"
asistente-ejecucion-manual paso a paso + informe
Automatización con k0lmena
"Automatizá en k0lmena los casos de HU-001"
web-mapper después npm test, sin tokens
Gestión
"Subí los casos de HU-001 a Xray y creá el ciclo Sprint 5"
gestor-pruebas
"Subí los resultados de la última corrida al ciclo PROJ-60"
publicador-resultados estados y evidencias
Si falta un dato

El agente no inventa: devuelve "Necesito que confirmes" y Claude te pregunta.

Acciones con efecto

Escribir en una base, crear datos en Jira/Xray o correr carga: siempre con tu ok.

Ahorra tokens

Lo automatizado corre con npm test, sin agentes.
