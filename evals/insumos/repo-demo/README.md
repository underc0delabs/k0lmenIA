# Tienda demo

Tienda online de ejemplo (front en TypeScript). Módulos:

- `src/registro/` — alta de cuentas y validaciones del formulario.
- `src/pagos/` — carrito, cupones, envío y medios de pago.
- `src/i18n/` — textos de la interfaz.

Roles: `cliente` (compra) y `admin` (gestiona cupones y pedidos).
